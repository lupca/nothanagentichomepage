## 2. Tiêu Chuẩn Kỹ Thuật & Chất Lượng Code

- **Kiến trúc Plugin-based**: Hoàn thiện 2 lớp trừu tượng `AnalysisEngine` (phân tích AI/CV) và `DeviceProvider` (nguồn phát hình ảnh/video), sẵn sàng mở rộng mà không cần sửa core.
- **Không Fallback / Swallow Exception**: Toàn bộ hệ thống áp dụng bộ ngoại lệ `SOAIException`. Mọi sự cố (lỗi DB, file hỏng, QR mờ, lỗi FFmpeg...) đều quăng lỗi minh bạch kèm HTTP Response RFC-compliant và ghi log chi tiết.
- **Bảo mật**: Mã hóa Fernet cho thông tin đăng nhập camera/thiết bị, chống Path Traversal trên các API xem/tải file.
- **Frontend & UI**: Giao diện React 18 + Vite + Tailwind CSS tối tân, hỗ trợ đầy đủ 7 màn hình chuyên biệt (đã build thành công bản production tại `frontend/dist/`).
